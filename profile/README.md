<h3 align="center">Steerglass</h3>

<p align="center">
  A fast, native desktop app to browse, debug and operate many Kubernetes clusters at once.<br>
  macOS, Windows and Linux · open source (Apache-2.0)
</p>

<p align="center">
  <a href="https://steerglass.com">Website</a> ·

  <a href="https://github.com/steerglass/steerglass">Source</a> ·
  <a href="https://steerglass.com/changelog/">Changelog</a>
</p>

---

- **Every cluster in one window**: an overview of all your contexts, with what needs attention
  across them, and the same table for many clusters at once.
- **Fast**: a native app (Rust and Tauri), live updates over watches, thousands of rows without lag.
- **Safe on production**: clusters you mark as production ask for confirmation before any change.
- **Optional AI help, with your own model**: explains a failing object from its YAML, events and logs.
  Off by default; requests go straight to the provider you choose.

Install on macOS with `brew install --cask steerglass/tap/steerglass`, or get the installer for your
system at [steerglass.com/install](https://steerglass.com/install/).

Bugs and ideas are welcome in [issues](https://github.com/steerglass/steerglass/issues).
